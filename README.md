# 찬양 쇼츠 메이커

예배·찬양 유튜브 영상에서 **찬양 부분만** 골라, 가사 자막이 들어간 세로 쇼츠(1080×1920)로 만들어 주는 Windows 프로그램입니다.

## 📥 다운로드

**[설치 파일 받기 (Windows)](https://github.com/smdjoo-stack/praise-shorts-maker/releases/latest)** → `PraiseShortsMaker-Setup-1.0.0.exe`

## 할 수 있는 것

- **AI가 찬양 자동 찾기**: 영상의 소리를 듣고 노래하는 부분만 곡별로 찾습니다. 설교·기도·광고는 빠집니다.
- **시간 직접 입력**: `12:30 - 16:45 곡제목`처럼 한 줄에 한 곡씩 적으면 그 구간을 그대로 자릅니다.
- **가사 자막**: AI가 받아 적은 가사를 한 줄씩 자막으로 넣습니다. 틀린 글자는 직접 고칠 수 있습니다.
- **길이**: 후렴 1분 / 1분 30초 / 최대 3분 / 곡 전체
- **템플릿**: 다크 / 라이트, 제목 색·자막 크기와 위치 조절

## 설치

1. 설치 파일을 받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(코드 서명 인증서가 없어서 뜨는 경고입니다).
3. 처음 실행할 때 [Gemini API 키](https://aistudio.google.com/apikey)(무료)를 넣습니다. 키는 이 컴퓨터에만 저장됩니다.

## 참고

- 설교 쇼츠 메이커(Rojaewon)를 바탕으로 찬양용으로 고쳐 만들었습니다.
- 본인이 권리를 가진 영상(예: 소속 교회가 올린 영상)에만 사용하세요. 찬양곡 자체의 저작권(CCLI 등)도 확인이 필요합니다.
